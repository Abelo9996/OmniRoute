- **fix(api):** the leaderboard SSE stream (`/api/gamification/stream`) and the embedded-service log tail (`/api/services/[name]/logs`) now release their timers and ring-buffer subscription when the response body is cancelled or a write fails, not only when the request signal aborts. A half-open peer (tunnel drop, network change) never aborts the signal, so these streams used to keep polling and queueing for the life of the process. The leaderboard stream also closes immediately when the client disconnected before auth finished.
