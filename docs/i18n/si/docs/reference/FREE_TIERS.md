## TL;DR — OmniRoute ඇත්ත වශයෙන්ම කොපමණ නොමිලේ inference ප්රමාණයක් ඒකාබද්ධ කරන්නේද?

මෙම සංඛ්යා නාමාවලිය පුරා ඇති වෙන වෙනම තෙවන පාර්ශ්ව ගිණුම් සහ සුදුසුකම් කොන්දේසි විස්තර කරයි. OmniRoute මෙම අයවැය ප්රදානය නොකරයි: ඔබ අවශ්ය ගිණුම් හෝ අක්තපත්ර ලබාගෙන, සුදුසුකම් ඇති සැපයුම්කරුවන් සම්බන්ධ කර, ඔවුන්ගේ සීමාවන්ට ගරු කළ යුතුය. සුදුසුකම් ඇති route එකක් නොමැති නව ස්ථාපනයකදී ශුන්ය වීම ඇතුළුව, ඇත්ත වශයෙන්ම භාවිත කළ හැකි ධාරිතාව අඩු විය හැක. `tos: avoid` ලෙස සලකුණු කළ සැපයුම්කරුවන් පෙරනිමියෙන් ස්වයංක්රීය routing වෙතින් බැහැර කර ඇත.

## අපගේ සංඛ්යාව අනෙකුත් එකතුකරන්නන්ගේ සංඛ්යාවලට වඩා කුඩා වන්නේ ඇයි

මෙම ක්ෂේත්රයේ බොහෝ "මසකට නොමිලේ ටෝකන" සංඛ්යා එක් එක් මොඩලයට අදාළ ලේබලවල එකතුවකි. අපගේ සංඛ්යාව එසේ නොවන්නේ හිතාමතාමය:

- **සෑම හවුල් සංචිතයක්ම ගණන් කරන්නේ එක් වරක් පමණි.** Mistral හි නොමිලේ සැලැස්ම යනු එක් සංවිධානයකට මසකට 1Bක එක් දීමනාවකි; එය මොඩල පහක් යටතේ ලැයිස්තුගත කිරීමෙන් එය 5Bක් නොවේ. එක් එක් මොඩලය අනුව එකතු කළහොත්, අපගේම නාමාවලියෙහි අගය **~7.4B** ලෙස දැක්වෙනු ඇත (2026-09-03 දින නැවත ගණනය කරන ලදී; මෙම අගය CI මඟින් පාලනය නොවේ — නාමාවලිය වෙනස් වන සෑම විටම එය නැවත මනින්න) — ප්රධාන ශීර්ෂයෙහි **~1.47B** ලෙස සඳහන් වන්නේ එක් එක් සැපයුම්කරු සඳහා එක් ගිණුමකට සැබවින්ම වැය කළ හැකි ප්රමාණය එය වන බැවිනි.
- **දෛනික සීමා පරිවර්තනය කරන නමුත්, අනුපාත එසේ නොකරයි.** ලේඛනගත tokens/day සීමාවක් `× 30` බවට පත් වේ; ලේඛනගත requests/day සීමාවක් `RPD × ~800 tokens × 30` බවට පත් වේ; requests-per-minute පමණක් ප්රකාශයට පත් කරන සැපයුම්කරුවකුට මාසික අගයක් **නොමැති** අතර, එය කිසිවිටෙක එකතුවට ඇතුළත් නොකර _uncapped_ ලෙස ලැයිස්තුගත කෙරේ. අනුපාත සීමාවක් 24/7න් ගුණ කිරීම අප ප්රතික්ෂේප කරන අතිශයෝක්තියයි.
- **ප්රාදේශීය අනන්යතා පරීක්ෂාවක් පිටුපස ඇති කෝටා වෙනම පෙන්වයි** (`+~6M behind regional identity verification`), මන්ද බොහෝ පාඨකයන්ට ඒවා භාවිත කළ නොහැකි බැවිනි.
- **ලියාපදිංචි වීමේ බැර පළමු මාසයට පමණක් අදාළය** සහ ඒවා ස්ථාවර සංඛ්යාව සමඟ කිසිවිටෙක මිශ්ර නොකර, දෙවන අගයක් ලෙස වාර්තා කෙරේ.
- **මෙම අගය CI මඟින් බලාත්මක කෙරේ.** `npm run check:docs-counts` නාමාවලියෙන් එකතු නැවත ගණනය කරන අතර, මෙම ගොනුව, README හෝ අයවැය කාඩ්පත එම අගයන්ගෙන් වෙනස් වූ විට build එක අසාර්ථක කරයි.

## ToS අවධානය යොමු කළ යුතු වගුව

> **ToS සලකුණ උපදේශාත්මක එකක් මිස routing gate එකක් නොවේ.** `tos` ලෙස සලකුණු කර ඇති සැපයුම්කරුවන් පෙරනිමියෙන් routing සහ combo/fallback සඳහා තවමත් ඇතුළත් වේ; එම සලකුණ දිස්වන්නේ `/dashboard/free-tiers` සහ `/api/free-tier/summary` මත පමණි. `excludeTosAvoid` query parameter එක බලපාන්නේ summary view එකට පමණක් වන අතර, global routing වෙත නොවේ. තීරණය `open-sse/config/freeTierCatalog.ts` තුළ පවතී (තොරතුරුමය පමණි, routing engines මඟින් කියවනු නොලැබේ).

> ස්වයං-සත්කාරක, තනි-පරිශීලක පුද්ගලික proxy එකක් සඳහා එක් එක් සැපයුම්කරුගේ කොන්දේසි පිළිබඳ ඉක්මන් කියවීමක්. `caution` = පරීක්ෂා කිරීම වටින පුද්ගලික-භාවිත හෝ proxy වගන්තියක්; `ambiguous` = අපැහැදිලියි; `ok` = පැහැදිලිව අවසර දී ඇත. මෙය තොරතුරු සඳහා පමණක් වන අතර නීති උපදෙස් නොවේ — තීරණය ඔබ සතුය.

### ⚠️ අවධානය — පරීක්ෂා කිරීම වටින පුද්ගලික-භාවිත / proxy වගන්ති (16)

> ඔවුන්ගේ නොමිලේ ප්රවේශය සැබෑ එකක් වන අතර OmniRoute හට ඔවුන් වෙත route කළ හැකිය; පහත වගන්ති දැනගැනීම වටී. OAuth/keyless ඒවා ටෝකනවලින් ප්රමාණනය කළ නොහැකි බැවින්, ඒවා ප්රධාන ශීර්ෂයේ සංඛ්යාවට ඇතුළත් නොවේ (ඒවා භාවිත කළ නොහැකි නිසා නොවේ).
