## Кратко — какой объём бесплатного инференса фактически агрегирует OmniRoute?

Эти показатели относятся к отдельным учётным записям сторонних сервисов и различным условиям участия в рамках каталога. OmniRoute не предоставляет этот бюджет: вам необходимо получить требуемые учётные записи или учётные данные, подключить подходящих провайдеров и соблюдать их ограничения. Фактически доступный объём может быть меньше, вплоть до нуля в новой установке без подходящего маршрута. Провайдеры с пометкой `tos: avoid` по умолчанию исключены из автоматической маршрутизации.

**Проверено 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) предоставляет разовый промокредит в размере $5, для получения которого требуется указать способ оплаты; срок его действия истекает через 30 дней. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) публикует ограничения частоты запросов по проектам, моделям и тарифам; он по-прежнему не включён в количественный итоговый показатель за месяц.

| Метрика                                                | Токенов в месяц                      | Значение                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------ | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документированная регулярная квота**                 | **~1.62B**                           | **Пулы** бесплатных тарифов (в каталоге для каждой модели), каждый общий пул учитывается **один раз**. Актуальный источник данных для `/api/free-tier/summary` и страницы «Бюджет бесплатного тарифа» на панели управления. **Используйте это значение.**                                                                                                                     |
| **+ первый месяц с кредитами за регистрацию**          | **~2.22B**                           | Регулярная квота + разовые кредиты за регистрацию (Z.AI 20M, DeepSeek 5M, …), с устранением дублирования для каждой учётной записи. **Только первый месяц** — не возобновляется.                                                                                                                                                                                              |
| **+ бессрочно бесплатно, без опубликованного лимита**  | _не поддаётся количественной оценке_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальный регулярный доступ, ограниченный частотой запросов или параллелизмом, **без лимита токенов, который можно было бы учесть**. Указываются, но никогда не суммируются (учёт их по формуле `RPM×24/7` привёл бы к завышению, которого мы избегаем). |
| **+ увеличение после внесения депозита**               | **+~24M**                            | Разовое пополнение OpenRouter на **$10** увеличивает его бесплатный пул с 50 до 1000 запросов в день. Указывается отдельно, чтобы это значение никогда не завышало регулярный объём.                                                                                                                                                                                          |
| **+ после региональной проверки личности**             | **+~6M**                             | `modelscope` (привязка Alibaba Cloud + подтверждение настоящего имени в материковом Китае). Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в итоговый показатель: +~6M после региональной проверки личности.                                                              |
| Теоретический максимум (все ограничения частоты, 24/7) | ~10B                                 | Сумма ограничений частоты всех провайдеров, экстраполированная на непрерывное использование. **Не является гарантией** — не выносите это значение в заголовок.                                                                                                                                                                                                                |

**Честный итог:** _OmniRoute агрегирует **~1.62B документированных бесплатных токенов в месяц** (до ~2.22B в первый месяц с учётом кредитов за регистрацию) в рамках 35 пулов бесплатных тарифов — плюс длинный список бессрочно бесплатных провайдеров без фиксированного лимита, — а сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет использовать этот объём ещё эффективнее._

> **Почему показатель снизился с прежних ~1,94 млрд.** Обновление от 2026-06-17 — это уточнение ради достоверности, а не потеря: для `gemini` теперь устранено дублирование на уровне пула (ранее объём был завышен из-за отдельного учёта каждого варианта Flash, 462 млн → 60 млн), лимит `cloudflare-ai` исправлен до реальных 10 тыс. Neurons/день (122 млн → 30 млн), `doubao` переклассифицирован как разовый бонус за регистрацию (а не регулярный), а закрытые тарифы удалены (`chutes`/`phind`/`kluster` прекратили работу). Это частично компенсировано `llm7` (корректные 5 млн/день → 150 млн) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно скорректировано до ~1,37 млрд в v3.8.42:** `longcat` был переклассифицирован с регулярного лимита 150 млн/мес. на разовый бонус 10 млн за регистрацию после завершения бесплатного ознакомительного периода. Применяется то же правило достоверности — ни один провайдер не был удалён по ошибке.
>
> **Обновлено 2026-08-26 после вывода Felo Web из эксплуатации:** Felo Web исключён, пока происхождение/лицензирование его компонентов на основе GPL остаётся на ПАУЗЕ; на тот момент источник сообщал о 38 ключах пула. Количество пулов обновляется в реальном времени и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют количество токенов (Google удалил бесплатную таблицу по моделям 2025-12-23; бесплатный план Ollama предоставляет «начальные кредиты на использование») и теперь указаны как **безлимитные**, поэтому никогда не суммируются (−80 млн); `groq` имеет пять лимитов по 200 тыс. TPD **на каждую модель** (по 6 млн, +15 млн), при этом три выведенных из эксплуатации идентификатора удалены; `nara` имеет единый пул 7 млн/день (+60 млн, 210 млн). Лимит `mistral` в 1 млрд виден только в консоли аккаунта — см. раздел _Классы доказательств_ в Методологии.
>
> **Исправлено 2026-09-03 (#11773):** `cerebras` был переклассифицирован с регулярного лимита 30 млн/мес. (прежний пробный тариф без карты с 1 млн токенов/день) на разовый бонус $5 за регистрацию, для которого требуется способ оплаты. Применяется то же правило достоверности, что и для LongCat.
>
> **Плюс xKiro (2026-09-03):** новый пул `xkiro-free` (150 млн/мес.) добавляет 35-й регулярный ключ пула. Felo Web остаётся исключённым, пока происхождение/лицензирование его компонентов на основе GPL остаётся на ПАУЗЕ. Теперь источник сообщает о **35 регулярных ключах пула** и **~1,62 млрд стабильного объёма** — это актуальное число, контролируемое CI (`check:docs-counts` завершает сборку с ошибкой, если оно расходится с `computeFreeModelTotals()`).

Крупнейшие **документально подтверждённые** источники: `mistral` — 1,00 млрд, `nara` — 210 млн, `llm7` — 150 млн, `xkiro` — 150 млн, `groq` — 30 млн (пять лимитов на отдельные модели), `cloudflare-ai` — 30 млн, `api-airforce` — 24 млн. (`longcat` исключён — его лимит LongCat-2.0 в 10 млн является разовым бонусом за регистрацию с обязательной процедурой KYC, а не регулярным ежемесячным бюджетом.)

> ⚠️ Теоретический максимум (~10 млрд) завышен из-за провайдеров, ограниченных только частотой запросов и **не публикующих лимит токенов** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), показатели которых рассчитывались бы как `RPM/TPM × 24/7 × 30d` — теоретический максимум, который не сможет стабильно использовать ни один аккаунт. Они **исключены** из обоснованного показателя (вместо этого приведены в строке «навсегда бесплатно, без лимита»). Именно такое завышение делает многомиллиардные заявления конкурентов ненадёжными.

## Обновление от 2026-06-17 — что изменилось с 2026-06-05

Весь каталог был обновлён по результатам веб-исследования с участием 50 агентов (официальная документация + новости за последние 7 дней, с перекрёстной проверкой спорных данных). Основные изменения:

- **Удалены / нет бесплатного тарифа (2026):** `chutes` (бесплатный тариф закрыт в 2026-03), `phind` (компания прекратила работу в 2026-01), `kluster` (закрыт 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатный доступ к MiMo отозван 2026-05-24, промоакция Nemotron завершилась в 2026-06 — повторно проверено 2026-06-18), `aimlapi` (бесплатный тариф приостановлен — повторно проверено 2026-06-18), `yi` (Yi-Light выведен из эксплуатации, оплата по мере использования — повторно проверено 2026-06-18), `featherless-ai` (в настоящее время бесплатного тарифа нет), `chipotle` («Pepper AI» от Chipotle — обратно спроектированный виджет чата Amelia по адресу `amelia.chipotle.com`, с которым взаимодействовал провайдер, теперь возвращает 404 по всем маршрутам, включая корневой; бэкенд выведен из эксплуатации/перемещён, подтверждено 2026-09-15 — полностью удалён из каталога, #13131/#4037). `iflytek` / `sparkdesk` остаются в списке, но снабжены предупреждением об условиях использования (Spark Lite бесплатен; условия использования ограничивают применение в качестве прокси/ретранслятора).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` отключены 2026-06-01, а `2.5 Pro` исключён из бесплатного тарифа (2026-04); теперь бесплатный тариф включает **только семейство Flash** (2.5/3/3.1/3.5 Flash + Gemma). Теперь каталог **объединяет в один пул** семейство Flash (ранее показатель был завышен из-за отдельного подсчёта каждого варианта: 462M → 60M).
- **Исправленные показатели:** `cloudflare-ai` 122M → **30M** (реальные 10k Neurons/день), `doubao` переклассифицирован как однократный приветственный кредит (а не возобновляемый), `llm7` 4M → **150M** (задокументировано 5M токенов/день), конечные точки `together` с суффиксом «-Free» отключены → приветственный кредит $25 также удалён (требуется минимальная покупка на $5, бесплатного пробного периода нет), период Preview для `longcat` завершён + модели Flash выведены из эксплуатации → осталась только **LongCat-2.0**, переклассифицированная как однократный приветственный кредит на **10M** токенов (требуется KYC, не возобновляется).
- **Обнаружены новые бесплатные провайдеры:** ⭐ **Kilo Code** (`kilo-gateway` — ротируемый набор «Auto Free»: семейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротируемых бесплатных моделей для программирования), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash навсегда бесплатны + приветственный бонус 20M), а также `arcee-ai` Trinity Large Preview.
- **Новые объективные категории тарифов** (см. «Методология»): категория _постоянно бесплатных без установленного лимита_ (реальный возобновляемый доступ без лимита токенов, который можно было бы подсчитать) и _увеличение лимита после внесения депозита_ (OpenRouter $10 → +24M/мес.); обе отображаются **отдельно**, чтобы они никогда не завышали основной показатель.

## Исправления для Bytez и Nous от 2026-10-15

[Биллинг Bytez](https://docs.bytez.com/model-api/docs/billing) ограничивает открытые модели на тарифе Free моделями с 7B параметров. Записи для моделей с 70B и 72B параметров требуют разблокировки посредством покупки кредитов и были удалены. Mistral-7B остаётся `recurring-credit`: кредиты обновляются каждые четыре недели, однако плата взимается за каждую секунду инференса, а лимит токенов не опубликован. Для счётчиков токенов установлено нулевое значение, обозначающее неизвестное количество и заменяющее неподтверждённую оценку в 1M токенов; это не означает отсутствие бесплатных кредитов. Изменения Nous подробно описаны в примечании к провайдеру ниже.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» с помощью двух режимов, которые намеренно используют
разные источники:

| Режим                     | Источник истины                                                                                                                                                              | Области применения                                                                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Итоговый каталог — поставляемая базовая версия с наложенными данными Radar (`getRadarCatalog`)                                                                               | Общие показатели бесплатного уровня, карточка бюджета, панели мониторинга                                                                        |

## Методология и оговорки

- Числа являются **оценками верхней границы**, основанными на документированных ограничениях бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранными посредством веб-исследования. Бесплатные уровни постоянно меняются — перепроверьте данные, прежде чем полагаться на конкретное значение.
- **Что фактически подтверждает запись.** Ни одна запись не содержит индивидуальной оценки достоверности, и API её также не предоставляет — рассматривайте каждое приведённое выше значение как оценку одного и того же, неуказанного качества. Два факта отличаются, поскольку они курируются вручную, а не выводятся автоматически: 44 записи содержат независимо задокументированный жёсткий лимит (39 из них — строки xKiro, все с одинаковой суточной квотой), а 13 записей содержат раскрытие информации об обучении на запросах. `hardStopGuaranteed` устанавливается только тогда, когда в собственных условиях провайдера указано, что превышение бесплатной квоты приводит к отклонению запроса, а не к незаметному началу списания средств; источник указывается в комментарии рядом с записью. Значение никогда по умолчанию не устанавливается в `true`, а у записи, которую никто не проверял, оно остаётся незаданным. Поэтому отсутствие флага жёсткого лимита означает «не установлено», а не «известно, что начнётся списание средств». **Режим STRICT** (подключаемое ограничение маршрутизации `freeAccessPolicy=strict`) доверяет только записям с этим флагом; все остальные бесплатные уровни исключаются как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Когда ограничение фильтрует пул, видимый оператору журнал сообщает как количество исключений, так и долю `no-hard-stop` среди них.
- `estMonthlyFreeTokens` = только ежемесячно возобновляемые токены. **Одноразовые приветственные кредиты не возобновляются** и учитываются как 0. Прекращённые уровни также учитываются как 0.
- Суточный лимит токенов → `monthly = daily × 30`. Если документирован только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без суточного лимита) → **без верхнего предела** (см. ниже).
- **Постоянно бесплатно, но опубликованный лимит токенов отсутствует** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реальный, регулярно возобновляемый бесплатный доступ с ограничениями по частоте запросов или параллелизму. Мы классифицируем такие предложения как `recurring-uncapped` и **никогда не суммируем их** — умножение `RPM × 24/7 × 30d` дало бы фантастический верхний предел (такое завышение мы отвергаем). Они перечислены, чтобы вы знали об их существовании.
- **Увеличение после внесения депозита:** небольшое однократное пополнение, которое навсегда повышает бесплатную квоту (OpenRouter: $10 → 1000 запросов/день ≈ +24 млн/мес.). Указывается отдельным значением и не включается в основной показатель постоянной квоты.
- **Квоты с ограничением по соответствию требованиям** (`eligibilityGate: "regional-identity"`): реальная регулярно возобновляемая квота, которая становится доступна только после привязанной к региону проверки личности (в настоящее время — подтверждение настоящего имени в материковом Китае). Учитывается по тому же правилу дедупликации пулов в отдельном показателе (`gatedRecurringTokens`) и никогда не включается в основной показатель постоянной квоты. Режим (`freeType`) не изменяется, поэтому маршрутизация также остаётся неизменной.
- **Классы доказательств.** Правило: число в каталоге сопровождается ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная любому пользователю), `api-public` (эндпоинт провайдера без аутентификации, например публичный эндпоинт тарифов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (значение видно только в консоли учётной записи; в комментарии указывается, кто и когда его видел, а также публичная страница, подтверждающая существование лимита). Текущее состояние: пять блоков, повторно проверенных 2026-09-02, содержат такое доказательство (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, созданные до повторной проверки 2026-09-02, сохраняют результаты более раннего исследования до следующего изменения; любое **новое или изменённое** число без комментария с доказательством является ошибкой. В настоящее время только `mistral` имеет статус `console-verified`.

## Почему наше число меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой сфере — это суммы значений, указанных для отдельных моделей. Наш показатель намеренно рассчитывается иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный тариф Mistral предоставляет один лимит в 1B токенов в месяц на организацию; указание его для пяти моделей не превращает его в 5B. Если суммировать по моделям, для нашего собственного каталога получилось бы **~7.4B** (пересчитано 2026-09-03; этот показатель не контролируется CI — пересчитывайте его при каждом изменении каталога), но в заголовке указано **~1.47B**, поскольку именно столько фактически может израсходовать одна учетная запись у каждого провайдера.
- **Суточные лимиты пересчитываются, ограничения скорости — нет.** Документированный лимит токенов в день преобразуется с помощью `× 30`; документированный лимит запросов в день — с помощью `RPD × ~800 токенов × 30`; если провайдер публикует только число запросов в минуту, для него **не указывается** месячный объем, а тариф помечается как _безлимитный_ и никогда не включается в сумму. Умножение ограничения скорости на режим 24/7 — это завышение, от которого мы отказываемся.
- **Квоты, доступные только после региональной проверки личности, указываются отдельно** (`+~6M после региональной проверки личности`), поскольку большинство читателей не может ими воспользоваться.
- **Стартовые кредиты действуют только в первый месяц** и указываются отдельным значением, а не включаются в постоянный показатель.
- **Значение контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые показатели на основе каталога и завершает сборку с ошибкой, если данные в этом файле, README или карточке бюджета расходятся с ними.

## OpenCode Free: ограничение клиентского контракта (#14313)

Провайдер `opencode` без ключа (публичный `https://opencode.ai/zen/v1`) отклоняет любой запрос,
который не соответствует клиентскому контракту OpenCode, возвращая **403 `FreeTierError`** и
сообщение _«Бесплатный тариф OpenCode можно использовать только из OpenCode»_. Это
отказ на уровне запроса (одинаковый результат для каждой учетной записи при одной и той же структуре запроса), а не
блокировка модели или задержка повторного подключения — OmniRoute классифицирует его как `project_route_error`, пропускает
блокировку модели / задержку и (на синтетическом пути `noauth`) приостанавливает автоматический повторный выбор комбинации
на короткий TTL. Отправляйте запросы с непустым списком инструментов, `stream: true` и

## Глоссарий

| Термин                      | Значение                                                                       |
| --------------------------- | ------------------------------------------------------------------------------ |
| **RPM / RPD / RPH**         | Запросов в минуту / день / час                                                 |
| **TPM / TPD**               | Токенов в минуту / день                                                        |
| **Документированный лимит** | Провайдер публикует явный дневной/месячный лимит токенов (обоснованный бюджет) |
| **Теоретический максимум**  | `rate-limit × 24/7 × 30d` — максимум, а не гарантированный бюджет              |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                              |

> Создано на основе исследования отдельных провайдеров от 2026-06-05. Для обновления повторно запустите процесс исследования (см. `_tasks/features-v3.8.12`).
