> Stikala med izvajanjem, ki spreminjajo vedenje sistema OmniRoute **brez ponovne uvedbe**.
> Vsaka tukaj navedena zastavica je opredeljena v datoteki
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — edinem viru resnice. Nadzorna plošča in REST API podatke bereta iz
> te datoteke, zato je spodnja tabela ustvarjena tako, da se z njo ujema v razmerju 1 : 1.

---

## Kaj so funkcijske zastavice

Funkcijska zastavica je poimenovano stikalo (logična vrednost ali naštevanje), katerega vrednost je mogoče spremeniti med
izvajanjem in trajno shraniti v podatkovni zbirki, ne da bi bila potrebna ponovna uvedba procesa. Vsaka
zastavica je opisana z objektom `FeatureFlagDefinition`, ki vsebuje `key`, `label`,
`description`, `category`, `defaultValue`, `type` in namig `requiresRestart`.

### Vrstni red razreševanja

**Dejanska vrednost** zastavice se razreši s funkcijo
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) po naslednjem
prednostnem vrstnem redu (višja prednost prevlada):

1. **Preglasitev v podatkovni zbirki** — vrednost, shranjena v tabeli `key_value` v imenskem prostoru
   `feature_flags` (nastavljena prek nadzorne plošče ali REST API-ja).
2. **Okoljska spremenljivka** — `process.env[<KEY>]`, če je nastavljena in ni prazna.
3. **Privzeta vrednost definicije** — `defaultValue` iz datoteke `featureFlagDefinitions.ts`.

Logična zastavica se šteje za **omogočeno**, kadar je njena dejanska vrednost `"true"`,
`"1"` ali `"yes"` (glejte `isFeatureFlagEnabled()`).

> [!NOTE]
> Večina zastavic ima tudi ustrezno okoljsko spremenljivko z **enakim imenom**,
> dokumentirano v datoteki [`ENVIRONMENT.md`](./ENVIRONMENT.md). Preglasitev zastavice v podatkovni zbirki
> ima prednost pred to okoljsko spremenljivko. Zastavica z
> `requiresRestart: true` se takoj trajno shrani, vendar se znova prebere šele ob
> zagonu procesa — njen preklop na nadzorni plošči prikaže pasico **»Ponovno zaženi strežnik«**.

## Katalog zastavic

86 zastavic v 6 kategorijah. **Privzeto** pomeni privzeto vrednost definicije — vrednost,
ki se uporabi, kadar ni prisotna niti preglasitev v podatkovni zbirki niti okoljska spremenljivka.

- **Preklopnik** za logične zastavice in **spustni seznam** za zastavice tipa enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Oznaka vira** za vsako zastavico — `DB`, `ENV` ali `DEF` — ki prikazuje, od kod izvira
  dejanska vrednost.
- Gumb za **Ponastavitev** (prikazan samo za zastavice z virom `DB`) za opustitev prepisa
  in gumb za **Ponastavitev vseh prepisov** na dnu.
- Pasica **Ponovni zagon strežnika**, ko se spremeni zastavica `requiresRestart`.

### REST API

Vse operacije potekajo preko ene same poti:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Vsaka metoda zahteva avtenticirano sejo nadzorne plošče (`401` sicer).

#### `GET /api/settings/feature-flags`

Vrne vsako zastavico z njeno dejansko vrednostjo, virom in povzetkom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 77 flags
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastavi ali odstrani posamezen prepis. Telo: `{ key: string; value?: string }`.
Izpustitev `value` odstrani prepis (obnovi okolje / privzeto).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odgovor ponovi novo `effectiveValue`/`source`, `previousValue`/
`previousSource` in `requiresRestart`. Neznani ključi in vrednosti enum
izven obsega so zavrnjeni s `400`.

#### `DELETE /api/settings/feature-flags`

Počisti **vse** prepise DB naenkrat, s čimer se vsaka zastavica povrne na svojo vrednost okolja / privzeto vrednost. Vrne `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Zastavice z `requiresRestart: true` začnejo veljati šele po ponovnem nalaganju procesa.
> Potek ponovnega zagona nadzorne plošče pokliče `POST /api/restart` in nato poizveduje
> `GET /api/health/ping`, dokler strežnik ponovno ne deluje.

## Nadomestna rešitev za prekoračitev proračuna v sili

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, privzeto `true`) nadzoruje
brezplačno nadomestno pot v sili v
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Ko je omogočena, se zahteve, ki izčrpajo svoj proračun, preusmerijo k brezplačnemu
nadomestnemu ponudniku/modelu, namesto da bi bile takoj neuspešne. Nastavite jo na
`false` (ali `0`) — prek stikala na nadzorni plošči, preglasitve v zbirki podatkov
ali okoljske spremenljivke `OMNIROUTE_EMERGENCY_FALLBACK` — da onemogočite to
vedenje in omogočite, da zahteve z izčrpanim proračunom ne uspejo. (Na nadzorni
plošči je prikazano kot stikalo v zahtevah PR #3741 / #3752.)

Odgovor, posredovan prek te nadomestne rešitve, vsebuje
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, zato
lahko odjemalec ugotovi, da je bil preusmerjen, ne da bi moral primerjati
`X-OmniRoute-Provider` s svojo zahtevo. Pri vseh drugih odgovorih ta glava ni
prisotna.
