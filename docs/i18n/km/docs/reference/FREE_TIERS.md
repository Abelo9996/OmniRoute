## តារាងចំណុចដែលត្រូវយកចិត្តទុកដាក់ចំពោះ ToS

> **ទង់ ToS គ្រាន់តែជាការណែនាំ មិនមែនជារបាំង routing ទេ។** Provider ដែលត្រូវបានសម្គាល់ជា `tos` នៅតែត្រូវបានរួមបញ្ចូលក្នុង routing និង combo/fallback តាមលំនាំដើម; ទង់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ query parameter `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនប៉ះពាល់ដល់ routing សកលទេ។ សេចក្តីវិនិច្ឆ័យស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ផ្តល់ព័ត៌មានប៉ុណ្ណោះ និងមិនត្រូវបានអានដោយ routing engines ទេ)។

> នេះជាការពិនិត្យយ៉ាងរហ័សលើលក្ខខណ្ឌរបស់ provider នីមួយៗ សម្រាប់ proxy ផ្ទាល់ខ្លួនដែល host ដោយខ្លួនឯង និងប្រើដោយអ្នកប្រើតែម្នាក់។ `caution` = មានឃ្លាស្តីពីការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬ proxy ដែលគួរតែពិនិត្យ; `ambiguous` = មិនច្បាស់លាស់; `ok` = អនុញ្ញាតយ៉ាងច្បាស់លាស់។ សម្រាប់ផ្តល់ព័ត៌មានប៉ុណ្ណោះ មិនមែនជាដំបូន្មានផ្នែកច្បាប់ទេ — អ្នកជាអ្នកសម្រេចចិត្ត។
