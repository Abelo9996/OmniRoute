## สรุปย่อ — OmniRoute รวบรวมการอนุมานฟรีได้มากเพียงใดกันแน่?

ตัวเลขเหล่านี้อธิบายบัญชีบุคคลที่สามและเงื่อนไขคุณสมบัติที่แยกจากกันทั่วทั้งแค็ตตาล็อก OmniRoute ไม่ได้มอบงบประมาณนี้ให้คุณ: คุณต้องสมัครบัญชีหรือรับข้อมูลประจำตัวที่จำเป็น เชื่อมต่อผู้ให้บริการที่มีสิทธิ์ และปฏิบัติตามข้อจำกัดของผู้ให้บริการเหล่านั้น ความจุที่ใช้งานได้จริงอาจต่ำกว่านี้ รวมถึงอาจเป็นศูนย์ในการติดตั้งใหม่ที่ยังไม่มีเส้นทางที่มีสิทธิ์ ผู้ให้บริการที่ระบุ `tos: avoid` จะถูกยกเว้นจากการกำหนดเส้นทางอัตโนมัติตามค่าเริ่มต้น

**ตรวจสอบเมื่อ 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) มอบเครดิตส่งเสริมการขาย $5 แบบครั้งเดียว โดยต้องระบุวิธีการชำระเงินและเครดิตจะหมดอายุหลังจาก 30 วัน [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) เผยแพร่ขีดจำกัดอัตราการใช้งานตามโปรเจกต์/โมเดล/ระดับบริการ แต่ยังไม่รวมอยู่ในตัวเลขสรุปรายเดือนที่คำนวณปริมาณไว้

**พาดหัวที่ตรงไปตรงมา:** _OmniRoute รวบรวมโทเค็นฟรีที่มีเอกสารอ้างอิงประมาณ **~1.62B ต่อเดือน** (สูงสุดประมาณ ~2.22B ในเดือนแรกเมื่อรวมเครดิตสมัครใช้งาน) จากพูลแพ็กเกจฟรี 35 พูล — พร้อมผู้ให้บริการฟรีถาวรแบบไม่มีเพดานอีกเป็นจำนวนมาก — และการบีบอัดด้วย RTK + Caveman (ประหยัดโทเค็น 15–95%) ยังช่วยให้ใช้งานได้นานขึ้นอีก_

> **เหตุผลที่ตัวเลขนี้ลดลงจากเดิมประมาณ 1.94B** การรีเฟรชเมื่อ 2026-06-17 เป็นการแก้ไขตัวเลขให้ตรงตามความเป็นจริง ไม่ใช่การสูญเสียโควตา: ขณะนี้ `gemini` ถูกตัดรายการซ้ำในระดับพูลแล้ว (ก่อนหน้านี้ตัวเลขสูงเกินจริงเนื่องจากนับ Flash แต่ละเวอร์ชันแยกกัน จาก 462M → 60M), `cloudflare-ai` ถูกแก้ไขให้ตรงกับโควตาจริงที่ 10k-Neurons/วัน (122M → 30M), `doubao` ถูกจัดประเภทใหม่เป็นเครดิตสมัครใช้งานแบบครั้งเดียว (ไม่ใช่โควตาที่ได้รับซ้ำ) และนำระดับบริการที่ปิดตัวแล้วออก (`chutes`/`phind`/`kluster` ยุติให้บริการ) โดยมี `llm7` (แก้ไขเป็น 5M/วันที่ถูกต้อง → 150M) และผู้ให้บริการฟรีรายใหม่ (Kilo, OpenCode Zen, Z.AI GLM-Flash) ช่วยชดเชยบางส่วน
>
> **แก้ไขเพิ่มเติมเป็นประมาณ 1.37B ใน v3.8.42:** `longcat` ถูกจัดประเภทใหม่จากสิทธิ์ที่ได้รับซ้ำ 150M/เดือนเป็นเครดิตสมัครใช้งานแบบครั้งเดียว 10M หลังจากช่วงทดลองใช้ฟรีสิ้นสุดลง ใช้หลักความซื่อตรงเดียวกัน — ไม่มีผู้ให้บริการรายใดถูกนำออกโดยไม่ได้ตั้งใจ
>
> **อัปเดตเมื่อ 2026-08-26 หลังจากยุติการใช้งาน Felo Web:** Felo Web ถูกตัดออกในระหว่างที่แหล่งที่มา/สิทธิ์การใช้งานซึ่งมีที่มาจาก GPL ยังคงอยู่ในสถานะ HOLD; ณ เวลานั้นซอร์สรายงานคีย์พูล 38 รายการ จำนวนพูลเป็นข้อมูลสดและถูกตรวจสอบโดย CI (`check:docs-counts` จะทำให้บิลด์ล้มเหลวหากตัวเลขข้างต้นคลาดเคลื่อนจาก `computeFreeModelTotals()`)

| ระบอบ                  | แหล่งข้อมูลที่ถือเป็นจริง                                                                                                                                                                  | ส่วนที่ใช้งาน                                                                                                                                |

| **การนับ / การแสดงผล** | แค็ตตาล็อกที่ผ่านการประมวลผลแล้ว — ข้อมูลพื้นฐานที่มากับรุ่นเผยแพร่ซึ่งซ้อนทับด้วยฟีด Radar (`getRadarCatalog`)                                                                            | ยอดรวมระดับฟรี, การ์ดงบประมาณ, แดชบอร์ด                                                                                                      |
| **การตัดสินใจ**        | เฉพาะแค็ตตาล็อกที่มากับรุ่นเผยแพร่ (`FREE_MODEL_BUDGETS` ใน `open-sse/config/freeModelCatalog.data.ts`) รวมถึงฮิวริสติกภายในเครื่อง (คำต่อท้าย `:free`, ราคาเป็นศูนย์, `grantsFreeAccess`) | ผู้ใช้ทั้งหมดของ `src/shared/utils/freeModels.ts`: การนำเข้าโมเดล, การกำหนดเส้นทาง `auto/*`, `GET /v1/models` และตัวอย่างแสดงผลในเบราว์เซอร์ |

## ระเบียบวิธีและข้อควรระวัง

- ตัวเลขเป็น **ค่าประมาณขอบเขตบน** จากขีดจำกัดระดับฟรีที่ผู้ให้บริการแต่ละรายจัดทำเอกสารไว้ ณ วันที่ **2026-06-17** ซึ่งรวบรวมด้วยการค้นคว้าบนเว็บ ระดับฟรีเปลี่ยนแปลงอยู่เสมอ — โปรดตรวจสอบอีกครั้งก่อนนำตัวเลขไปใช้
- **สิ่งที่แต่ละรายการรับรองจริงๆ** ไม่มีรายการใดมีระดับความเชื่อมั่นเฉพาะแถว และ API ก็ไม่ได้ให้ข้อมูลดังกล่าว — ให้ถือว่าตัวเลขทั้งหมดข้างต้นเป็นค่าประมาณที่มีคุณภาพระดับเดียวกันซึ่งไม่ได้ระบุไว้ อย่างไรก็ตาม มีข้อเท็จจริงสองอย่างที่แตกต่างออกไป เพราะได้รับการดูแลด้วยตนเองแทนที่จะอนุมานขึ้นมา: 44 รายการมีจุดหยุดแบบตายตัวที่มีเอกสารยืนยันแยกต่างหาก (39 รายการในนั้นคือแถวของ xKiro ซึ่งทั้งหมดใช้โควตารายวันร่วมกันหนึ่งชุด) และ 13 รายการมีการเปิดเผยเรื่องการนำพรอมต์ไปใช้ฝึก `hardStopGuaranteed` จะถูกตั้งค่าเฉพาะเมื่อข้อกำหนดของผู้ให้บริการระบุเองว่า การใช้เกินโควตาฟรีจะทำให้คำขอถูกปฏิเสธ แทนที่จะเริ่มเรียกเก็บเงินโดยไม่แจ้งให้ทราบ โดยมีแหล่งข้อมูลอยู่ในความคิดเห็นถัดจากรายการนั้น ค่านี้จะไม่ถูกกำหนดเป็น `true` โดยปริยาย และรายการที่ยังไม่มีใครตรวจสอบจะไม่ถูกตั้งค่าไว้ ดังนั้น การไม่มีแฟล็กจุดหยุดแบบตายตัวจึงหมายถึง "ยังไม่มีข้อยืนยัน" ไม่ใช่ "ทราบแน่ชัดว่าจะเรียกเก็บเงิน" **โหมด STRICT** (กลไกป้องกันการกำหนดเส้นทาง `freeAccessPolicy=strict` ที่ต้องเลือกเปิดใช้) จะเชื่อถือเฉพาะรายการที่มีแฟล็กดังกล่าวเท่านั้น ระดับฟรีอื่นทั้งหมดจะถูกคัดออกในฐานะ `no-hard-stop` (ดู `open-sse/services/autoCombo/strictZeroCostFilter.ts`) เมื่อกลไกป้องกันกรองพูล บันทึกที่ผู้ดูแลระบบมองเห็นจะรายงานทั้งจำนวนที่ถูกคัดออกและสัดส่วน `no-hard-stop`
- `estMonthlyFreeTokens` = เฉพาะโทเค็นรายเดือนที่ได้รับเป็นประจำ **เครดิตสมัครใช้งานครั้งเดียวจะไม่เกิดซ้ำ** และนับเป็น 0 ระดับบริการที่ยุติไปแล้วก็นับเป็น 0 เช่นกัน
- ขีดจำกัดโทเค็นรายวัน → `monthly = daily × 30` หากมีเอกสารเฉพาะ RPD → `RPD × ~800 output tokens × 30` หากมีเฉพาะ RPM/TPM (ไม่มีขีดจำกัดรายวัน) → **ไม่จำกัดเพดาน** (ดูด้านล่าง)
- **ใช้ฟรีถาวร แต่ไม่มีการเผยแพร่ขีดจำกัดโทเค็น** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): บริการเหล่านี้ให้สิทธิ์ใช้ฟรีแบบเกิดซ้ำจริง โดยจำกัดอัตรา/จำนวนคำขอพร้อมกัน เราจัดประเภทบริการเหล่านี้เป็น `recurring-uncapped` และ **ไม่นำมารวมยอดโดยเด็ดขาด** — การคูณ `RPM × 24/7 × 30d` จะทำให้ได้เพดานในจินตนาการ (เป็นการเพิ่มตัวเลขเกินจริงที่เราไม่ยอมรับ) บริการเหล่านี้ถูกแสดงไว้เพื่อให้ทราบว่ามีอยู่
- **การเพิ่มโควตาหลังฝากเงินเพื่อปลดล็อก:** การเติมเงินจำนวนเล็กน้อยครั้งเดียวซึ่งเพิ่มโควตาฟรีอย่างถาวร (OpenRouter: $10 → 1000 คำขอ/วัน ≈ +24M/เดือน) รายงานเป็นตัวเลขแยกต่างหาก และไม่นำไปรวมในตัวเลขพาดหัวแบบคงที่
- **โควตาที่มีเงื่อนไขด้านสิทธิ์** (`eligibilityGate: "regional-identity"`): โควตาแบบเกิดซ้ำจริงซึ่งเปิดใช้ได้หลังผ่านการตรวจสอบตัวตนที่ผูกกับภูมิภาคเท่านั้น (ปัจจุบันคือการยืนยันชื่อจริงในจีนแผ่นดินใหญ่) นับโดยใช้กฎขจัดรายการพูลซ้ำแบบเดียวกันเป็นตัวเลขแยกต่างหาก (`gatedRecurringTokens`) และไม่นำไปรวมในตัวเลขพาดหัวแบบคงที่ ระบอบ (`freeType`) ยังคงเดิม ดังนั้นการกำหนดเส้นทางจึงไม่เปลี่ยนแปลง
- **ประเภทหลักฐาน** กฎคือ: ตัวเลขในแค็ตตาล็อกต้องอ้างอิงแหล่งที่มาในความคิดเห็น `// evidence:` ถัดจากรายการ — `public-page` (หน้าของผู้ให้บริการที่ทุกคนเข้าถึงได้), `api-public` (เอนด์พอยต์ของผู้ให้บริการที่เข้าถึงได้โดยไม่ต้องยืนยันตัวตน เช่น เอนด์พอยต์แผนบริการสาธารณะของ NaraRouter ที่ router.bynara.id) หรือ `console-verified <date> por <who>` (ตัวเลขมองเห็นได้เฉพาะภายในคอนโซลของบัญชี โดยความคิดเห็นจะบันทึกว่าใครเป็นผู้เห็นและเห็นเมื่อใด รวมถึงหน้าสาธารณะที่ระบุว่ามีขีดจำกัดดังกล่าว) สถานะในปัจจุบันคือ: ทั้งห้าบล็อกที่ได้รับการตรวจสอบซ้ำเมื่อ 2026-09-02 มีข้อมูลนี้ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); รายการที่มีอยู่ก่อนการตรวจสอบซ้ำในวันที่ 2026-09-02 จะสืบทอดผลการค้นคว้าก่อนหน้านี้จนกว่าจะถูกแก้ไข; ตัวเลขที่ **เพิ่มใหม่หรือเปลี่ยนแปลง** โดยไม่มีความคิดเห็นหลักฐานถือเป็นบั๊ก ปัจจุบันมีเพียง `mistral` เท่านั้นที่ได้รับการตรวจสอบผ่านคอนโซล

## เหตุใดตัวเลขของเราจึงน้อยกว่าของผู้รวบรวมรายอื่น

ตัวเลข "โทเค็นฟรีต่อเดือน" ส่วนใหญ่ในพื้นที่นี้เป็นผลรวมของตัวเลขที่ระบุแยกตามโมเดล แต่ของเราไม่ได้คำนวณเช่นนั้นโดยตั้งใจ:

- **พูลที่ใช้ร่วมกันแต่ละพูลจะถูกนับเพียงครั้งเดียว** แผนฟรีของ Mistral มีโควตา 1B/เดือนต่อองค์กรหนึ่งแห่ง การแสดงโควตานี้ภายใต้โมเดลห้าโมเดลไม่ได้ทำให้กลายเป็น 5B หากรวมแยกตามโมเดล แค็ตตาล็อกของเราเองจะมีตัวเลข **~7.4B** (คำนวณใหม่เมื่อ 2026-09-03; ตัวเลขนี้ไม่ได้ถูกตรวจสอบบังคับโดย CI — ให้วัดใหม่ทุกครั้งที่แค็ตตาล็อกเปลี่ยนแปลง) — ตัวเลขพาดหัวระบุ **~1.47B** เพราะนั่นคือจำนวนที่หนึ่งบัญชีจากผู้ให้บริการแต่ละรายสามารถใช้ได้จริง
- **เพดานรายวันจะถูกแปลง แต่อัตราจะไม่ถูกแปลง** เพดาน tokens/day ที่มีการระบุไว้จะคำนวณเป็น `× 30`; เพดาน requests/day ที่มีการระบุไว้จะคำนวณเป็น `RPD × ~800 tokens × 30`; ผู้ให้บริการที่เผยแพร่เฉพาะ requests-per-minute จะ **ไม่มี** ตัวเลขรายเดือนและจะแสดงเป็น _ไม่มีเพดาน_ โดยไม่นำมารวม การคูณขีดจำกัดอัตราด้วย 24/7 คือการขยายตัวเลขเกินจริงที่เราไม่ยอมทำ
- **โควตาที่ต้องผ่านการยืนยันตัวตนตามภูมิภาคจะแสดงแยกต่างหาก** (`+~6M behind regional identity verification`) เนื่องจากผู้อ่านส่วนใหญ่ไม่สามารถใช้งานได้
- **เครดิตสำหรับการสมัครใช้ได้เฉพาะเดือนแรก** และจะรายงานเป็นตัวเลขที่สอง โดยไม่นำไปรวมกับตัวเลขการใช้งานต่อเนื่อง
- **ตัวเลขนี้ถูกบังคับตรวจสอบโดย CI** `npm run check:docs-counts` จะคำนวณยอดรวมใหม่จากแค็ตตาล็อก และทำให้บิลด์ล้มเหลวเมื่อตัวเลขในไฟล์นี้ README หรือการ์ดงบประมาณไม่ตรงกับผลรวมดังกล่าว

## ตารางประเด็นที่ควรพิจารณาเกี่ยวกับ ToS

> **แฟล็ก ToS เป็นเพียงคำแนะนำ ไม่ใช่เงื่อนไขกีดกันการกำหนดเส้นทาง** ผู้ให้บริการที่ทำเครื่องหมาย `tos` จะยังคงรวมอยู่ในการกำหนดเส้นทางและ combo/fallback ตามค่าเริ่มต้น แฟล็กนี้เพียงแสดงผลบน `/dashboard/free-tiers` และ `/api/free-tier/summary` เท่านั้น พารามิเตอร์คิวรี `excludeTosAvoid` มีผลเฉพาะกับมุมมองสรุป ไม่ใช่การกำหนดเส้นทางโดยรวม ข้อสรุปอยู่ใน `open-sse/config/freeTierCatalog.ts` (ใช้เพื่อให้ข้อมูล และไม่ได้ถูกอ่านโดยเอนจินกำหนดเส้นทาง)

> สรุปฉบับย่อเกี่ยวกับข้อกำหนดของผู้ให้บริการแต่ละรายสำหรับพร็อกซีส่วนบุคคลแบบโฮสต์เองและมีผู้ใช้คนเดียว `caution` = มีข้อกำหนดเกี่ยวกับการใช้งานส่วนบุคคลหรือพร็อกซีที่ควรตรวจสอบ; `ambiguous` = ไม่ชัดเจน; `ok` = อนุญาตไว้อย่างชัดเจน ข้อมูลนี้มีไว้เพื่อให้ข้อมูล ไม่ใช่คำแนะนำทางกฎหมาย — คุณเป็นผู้ตัดสินใจ

## OpenCode Free: ข้อจำกัดของสัญญาไคลเอนต์ (#14313)

ผู้ให้บริการ `opencode` แบบไม่ใช้คีย์ (สาธารณะ `https://opencode.ai/zen/v1`) จะปฏิเสธคำขอใดๆ
ที่ไม่ตรงตามสัญญาไคลเอนต์ OpenCode ด้วย **403 `FreeTierError`** และข้อความ
_"แพ็กเกจฟรีของ OpenCode สามารถใช้งานได้จากภายใน OpenCode เท่านั้น"_ นี่เป็นการปฏิเสธ
ในระดับคำขอ (ให้ผลการตัดสินเหมือนกันในทุกบัญชีสำหรับรูปแบบคำขอเดียวกัน) ไม่ใช่การแบน
โมเดลหรือคูลดาวน์การเชื่อมต่อ — OmniRoute จะจัดประเภทกรณีนี้เป็น `project_route_error` ข้าม
การล็อกโมเดล / คูลดาวน์ และ (บนเส้นทาง `noauth` จำลอง) หยุดการเลือกชุดค่าผสมอัตโนมัติใหม่
ชั่วคราวตาม TTL ระยะสั้น ให้ส่งคำขอที่มีรายการเครื่องมือซึ่งไม่ว่างเปล่า, `stream: true` และ
ส่วนหัวเซสชัน/UA ของ OpenCode (`opencodeFreeTierContract.ts`) มิฉะนั้นจะได้รับ 403

| **โควตาที่มีการระบุอย่างเป็นทางการ** | ผู้ให้บริการเผยแพร่ขีดจำกัดโทเค็นรายวัน/รายเดือนอย่างชัดเจน (งบประมาณที่อ้างอิงได้) |
| **เพดานเชิงทฤษฎี**                   | `rate-limit × 24/7 × 30d` — ค่าสูงสุด ไม่ใช่งบประมาณที่ได้รับ                       |
| **Neuron**                           | หน่วยประมวลผลของ Cloudflare (~1 โทเค็นเอาต์พุต)                                     |

> สร้างขึ้นจากการวิจัยผู้ให้บริการแต่ละรายเมื่อ 2026-06-05 โปรดเรียกใช้เวิร์กโฟลว์การวิจัยอีกครั้ง (ดู `_tasks/features-v3.8.12`) เพื่ออัปเดตข้อมูล
