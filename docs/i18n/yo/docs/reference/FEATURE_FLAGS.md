> Àwọn tógù àsìkò-ṣiṣe tí ń yí ìhùwàsí OmniRoute padà **láìṣe àtúnkóṣiṣẹ́**.
> Gbogbo àmì tí a tò síbí ni a ṣàlàyé nínú
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — orísun òtítọ́ kan ṣoṣo. Dásíbọ́ọ̀dù àti REST API méjèèjì ń kà láti inú
> fáìlì yẹn, nítorí náà a ṣe àgbéjáde tábìlì tó wà nísàlẹ̀ láti bá a mu ní 1:1.

## Kí Ni Àwọn Àmì Ẹ̀yà

Àmì ẹ̀yà jẹ́ tógù tó ní orúkọ (boolean tàbí enum) tí a lè yí iye rẹ̀ padà ní
àsìkò-ṣiṣe, tí a sì lè fi pamọ́ sínú dátábésì, láìní láti tún ìlànà ṣiṣẹ́. A
ṣàpèjúwe àmì kọ̀ọ̀kan pẹ̀lú `FeatureFlagDefinition` kan tó ní `key`, `label`,
`description`, `category`, `defaultValue`, `type`, àti ìtọ́kasí `requiresRestart`.

### Ètò Ìpinnu

[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ló ń pinnu
**iye tó ń ṣiṣẹ́** fún àmì kan gẹ́gẹ́ bí àtòlẹ́sẹẹsẹ yìí (èyí tó ga jù ló borí):

1. **Ìṣàkóso láti DB** — iye tí a fi pamọ́ sínú tábìlì `key_value` lábẹ́
   àyè-orúkọ `feature_flags` (tí a ṣètò nípasẹ̀ dásíbọ́ọ̀dù tàbí REST API).
2. **Àyípadà àyíká** — `process.env[<KEY>]`, bí a bá ṣètò rẹ̀ tí kò sì ṣófo.
3. **Àìròtẹ́lẹ̀ ìtumọ̀** — `defaultValue` láti inú `featureFlagDefinitions.ts`.

A ka àmì boolean sí **tí a ti mú ṣiṣẹ́** nígbà tí iye tó ń ṣiṣẹ́ rẹ̀ bá jẹ́ `"true"`,
`"1"`, tàbí `"yes"` (wo `isFeatureFlagEnabled()`).

> [!NOTE]
> Ọ̀pọ̀ jù lọ àwọn àmì náà tún ní àyípadà àyíká tó bá wọn mu, pẹ̀lú **orúkọ kan náà**,
> tí a ṣàkọsílẹ̀ rẹ̀ nínú [`ENVIRONMENT.md`](./ENVIRONMENT.md). Ìṣàkóso àmì láti DB
> ní ipò gíga ju àyípadà àyíká yẹn lọ. A máa fi àmì tó ní
> `requiresRestart: true` pamọ́ lẹ́sẹ̀kẹsẹ̀, ṣùgbọ́n a kàn tún un kà nígbà tí ìlànà
> bá bẹ̀rẹ̀ — yíyí i padà máa ń fi àsíá **"Tún Sẹ́fà Bẹ̀rẹ̀"** hàn lórí dásíbọ́ọ̀dù.

lò nígbà tí kò sí ìkọlélórí DB tàbí oníyí àyíká.

## Yíyí Àwọn Àmì-ìdámọ̀

### Ojú-ìwé Ìṣàkóso

Lọ sí **Ojú-ìwé Ìṣàkóso → Àwọn Ètò → Àwọn Àmì-ìdámọ̀ Ẹ̀bùn**
(`/dashboard/settings/feature-flags`). Àtẹ náà
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ṣe àtìlẹ́yìn fún:

- **Wíwá** nípasẹ̀ kókó tàbí àpèjúwe, kí o sì **ṣe àlẹ̀mọ́** nípasẹ̀ ẹ̀ka (pẹ̀lú ìwòran àfikún ti **Requires Restart**).
- Àmì **yíyí** fún àwọn àmì-ìdámọ̀ boolean àti **àtòjọ-ìṣàfihàn** fún àwọn àmì-ìdámọ̀ enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Àmì **orísun** fún àmì-ìdámọ̀ kọ̀ọ̀kan — `DB`, `ENV`, tàbí `DEF` — tí ó fi hàn níbi tí ìwúlò tó wà níbẹ̀ ti wá.
- Bùtíní **Tún-ṣe** (tí a fi hàn fún àwọn àmì-ìdámọ̀ tí ó wá láti `DB` nìkan) láti yọ àyípadà kúrò, àti bùtíní **Tún Gbogbo Àwọn Àyípadà Ṣe** ní ìsàlẹ̀.
- Àfihàn **Tún Olùpèsè Bẹ̀rẹ̀** nígbà tí àmì `requiresRestart` bá yí padà.

Gbogbo iṣẹ́-ṣíṣe lọ nípasẹ̀ ọ̀nà kan ṣoṣo:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).

#### `PUT /api/settings/feature-flags`

Ṣètò tàbí yọ àyípadà kan ṣoṣo kúrò. Ara: `{ key: string; value?: string }`.
Yíyọ `value` kúrò yóò yọ àyípadà náà kúrò (tí yóò mú àyíká / àyípadà àtìbẹ̀rẹ̀ padà wá).

```bash
# Ṣètò àyípadà DB kan
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Yọ àyípadà náà kúrò (kò sí "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ìdáhùn náà yóò tún fi `effectiveValue`/`source` tuntun hàn, `previousValue`/
`previousSource` àtijọ́, àti `requiresRestart`. Àwọn kókó tí a kò mọ̀ àti àwọn ìwúlò enum tí ó kọjá ààlà ni a óò kọ pẹ̀lú `400`.

#### `DELETE /api/settings/feature-flags`

Ó pa gbogbo àwọn àyípadà DB rẹ́ lẹ́ẹ̀kan náà, tí ó sì mú gbogbo àmì-ìdámọ̀ padà sí àyíká / ìwúlò àtìbẹ̀rẹ̀ rẹ̀. Ó dá `{ cleared: <count>, message: "..." }` padà.

> [!ÀKÍYÈSÍ]
> Àwọn àmì-ìdámọ̀ pẹ̀lú `requiresRestart: true` yóò wúlò nìkan lẹ́hìn tí a bá tún ìṣiṣẹ́ bẹ̀rẹ̀. Ìṣiṣẹ́ tún-bẹ̀rẹ̀ ti ojú-ìwé ìṣàkóso yóò pe `POST /api/restart` lẹ́yìn náà yóò máa ṣàyẹ̀wò `GET /api/health/ping` títí olùpèsè yóò fi padà sípò.

## Ọ̀nà Àfẹ́yinti Pajawiri fún Ìnáwó

`OMNIROUTE_EMERGENCY_FALLBACK` (ẹ̀ka `runtime`, àìpé `true`) ń ṣàkóso
ọ̀nà àfẹ́yinti ọ̀fẹ́ pajawiri nínú
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nígbà tí a bá mú un ṣiṣẹ́, àwọn ìbéèrè tí ìnáwó wọn bá tán ni a máa darí sí
olùpèsè/àwòṣe àfẹ́yinti ọ̀fẹ́ dípò kí wọ́n kùnà pátápátá. Ṣètò rẹ̀ sí `false` (tàbí `0`) — nípasẹ̀
bọ́tìnì ìṣàkóso lórí dashboard, àtúnṣe DB, tàbí oníyí àyíká
`OMNIROUTE_EMERGENCY_FALLBACK` — láti pa ìhùwàsí náà, kí àwọn ìbéèrè tí
ìnáwó wọn ti tán sì kùnà. (A ṣàfihàn rẹ̀ gẹ́gẹ́ bí bọ́tìnì ìṣàkóso lórí dashboard nínú PRs #3741 / #3752.)

Ìdáhùn tí ọ̀nà àfẹ́yinti yìí pèsè ní
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, nítorí náà
oníbàárà lè mọ̀ pé a tún darí rẹ̀ láìfi `X-OmniRoute-Provider` wé
ìbéèrè rẹ̀ láti wá ìyàtọ̀. Àkọlé yìí kò sí nínú gbogbo ìdáhùn mìíràn.
