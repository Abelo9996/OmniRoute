## TL;DR — ìwọ̀n inference ọ̀fẹ́ mélòó ni OmniRoute ń ṣàkójọpọ̀ ní ti gidi?

Àwọn iye wọ̀nyí ṣàlàyé àwọn àkọọ́lẹ̀ ẹnikẹ́ta ọ̀tọ̀ọ̀tọ̀ àti àwọn à条件 yíyẹ káàkiri àkójọ náà. OmniRoute kò fún ọ ní ìnáwó yìí: o gbọ́dọ̀ gba àwọn àkọọ́lẹ̀ tàbí ẹ̀rí ìdánimọ̀ tó yẹ, so àwọn olùpèsè tó yẹ pọ̀, kí o sì bọ̀wọ̀ fún àwọn ààlà wọn. Agbára tí o lè lò ní ti gidi lè kéré sí i, títí kan òdo lórí ìgbékalẹ̀ tuntun tí kò ní ipa-ọ̀nà tó yẹ. A máa yọ àwọn olùpèsè tí a fi `tos: avoid` sàmì sí kúrò nínú ìdarí aládàáṣiṣẹ́ ní àtètèkọ́ṣe.

**A ṣàyẹ̀wò ní 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) ń fúnni ní kirẹditi ìpolówó $5 lẹ́ẹ̀kan ṣoṣo, tó nílò ọ̀nà ìsanwó, tí yóò sì parí lẹ́yìn ọjọ́ 30. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) ń tẹ àwọn ààlà ìwọ̀n lílò fún iṣẹ́-àkànṣe/model/ìpele jáde; ó ṣì wà lẹ́yìn àkòrí oṣooṣù tí a fi iye hàn.

> **A tún ṣàtúnṣe rẹ̀ sí ~1.37B nínú v3.8.42:** a tún pín `longcat` láti ẹ̀bùn 150M/oṣù tó ń tún wá sí kirẹ́díìtì ìforúkọsílẹ̀ 10M ẹ̀ẹ̀kan ṣoṣo lẹ́yìn tí àgbéjáde àkọ́kọ́ ọ̀fẹ́ rẹ̀ parí. Òfin òtítọ́ kan náà — kò sí olupèsè kankan tí a yọ kúrò látàrí àṣìṣe.

Ìkà pool náà jẹ́ tààrà, CI sì ń ṣọ́ ọ (`check:docs-counts` yóò mú kí build kùnà bí àwọn nọ́ńbà òkè bá yàtọ̀ sí `computeFreeModelTotals()`).
>
> **A tún ṣàyẹ̀wò rẹ̀ ní 2026-09-02 pẹ̀lú àwọn ojúewé àwọn olupèsè fúnra wọn** (àwọn orísun: àwọn àlàyé `// evidence:` tó wà lẹ́gbẹ̀ẹ́ àkọsílẹ̀ kọ̀ọ̀kan tí a tún ṣàyẹ̀wò nínú `open-sse/config/freeModelCatalog.data.ts`): `gemini` àti `ollama-cloud` kò tẹ iye token jáde mọ́ (Google yọ tábìlì ọ̀fẹ́ fún model kọ̀ọ̀kan ní 2025-12-23; ètò Free ti Ollama jẹ́ "kirẹ́díìtì lílo fún ìbẹ̀rẹ̀") a sì ti tò wọ́n sí **àìní òpin**, a kì í kó wọn sínú àpapọ̀ rárá (−80M); `groq` ní òpin 200K-TPD márùn-ún **fún model kọ̀ọ̀kan** (6M kọ̀ọ̀kan, +15M), pẹ̀lú yíyọ ID mẹ́ta tí a ti fi sí ìfẹ̀yìntì; `nara` jẹ́ bucket 7M/ọjọ́ kan ṣoṣo (+60M, 210M). 1B ti `mistral` hàn nínú console àkọọ́lẹ̀ nìkan — wo _Àwọn ìpele ẹ̀rí_ lábẹ́ Ọ̀nà Ìṣèwádìí.
>
> **A ṣàtúnṣe ní 2026-09-03 (#11773):** a tún pín `cerebras` láti ẹ̀bùn 30M/oṣù tó ń tún wá (àdánwò àtijọ́ ti 1M token/ọjọ́ tí kò béèrè káàdì) sí kirẹ́díìtì ìforúkọsílẹ̀ $5 ẹ̀ẹ̀kan ṣoṣo tó nílò ọ̀nà ìsanwó. Òfin òtítọ́ kan náà bí ti LongCat.
>
> **Àfikún xKiro (2026-09-03):** pool `xkiro-free` tuntun (150M/oṣù) fi kọ́kọ́rọ́ pool tó ń tún wá kọkànlélọ́gbọ̀n kún un. Felo Web ṣì kò sí nínú ìṣírò nígbà tí orísun/ìwé-àṣẹ rẹ̀ tó jẹ jáde láti GPL ṣì wà ní DÍDÚRÓ. Orísun náà jábọ̀ **àwọn kọ́kọ́rọ́ pool tó ń tún wá 35** àti **~1.62B tó dúró ṣinṣin** báyìí — nọ́ńbà tààrà tí CI ń ṣọ́ (`check:docs-counts` yóò mú kí build kùnà bí èyí bá yàtọ̀ sí `computeFreeModelTotals()`).

Àwọn olùkópa **tí ẹ̀rí wọn wà nínú ìwé** tó tóbi jù lọ: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (òpin márùn-ún fún model kọ̀ọ̀kan), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` kò sí nínú ìṣírò — ẹ̀bùn LongCat-2.0 10M rẹ̀ jẹ́ kirẹ́díìtì ìforúkọsílẹ̀ ẹ̀ẹ̀kan ṣoṣo tó nílò KYC, kì í ṣe ìnáwó oṣooṣù tó ń tún wá.)

> ⚠️ Òrùlé àbá-èrò (~10B) pọ̀ ju òtítọ́ lọ nítorí àwọn olupèsè tó ní òpin ìwọ̀n ìbéèrè nìkan láìsí **òpin token tí a tẹ̀ jáde** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), tí iye wọn yóò jẹ́ `RPM/TPM × 24/7 × 30d` — ìwọ̀n gíga jù lọ ní àbá-èrò tí kò sí àkọọ́lẹ̀ kan ṣoṣo tó lè máa tẹ̀síwájú lórí rẹ̀. A **kò fi wọ́n sínú** iye tí a lè gbèjà (dípò bẹ́ẹ̀, a fi wọ́n hàn ní ìlà "ọ̀fẹ́ títí láé, kò sí òpin"). Ìpọ̀jù kan náà yìí ló mú kí àwọn ìsọ̀rí ọ̀pọ̀ bílíọ̀nù ti àwọn olùdíje má ṣe ṣeé gbẹ́kẹ̀ lé.

## Ìlànà méjì — kíkà sí i àti ṣíṣe ìpinnu

OmniRoute ń dáhùn ìbéèrè "ṣé ó jẹ́ ọ̀fẹ́?" nípasẹ̀ ìlànà méjì tí a mọ̀ọ́mọ̀ ṣe kí wọ́n ka àwọn orísun tó yàtọ̀:

| Ìlànà                  | Orísun òtítọ́                                                                                                                                                                              | Àwọn ibi tí ó ti farahàn                                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kíkà sí i / àfihàn** | Kátálọ́ọ̀gù tí a ti yanjú — ìpìlẹ̀ tí a pín jáde, tí ìfúnni Radar fi àfikún bo (`getRadarCatalog`)                                                                                           | Àpapọ̀ ipele-ọ̀fẹ́, káàdì ìnáwó, àwọn pánẹ́ẹ̀lì ìṣàkóso                                                                                          |
| **Ṣíṣe ìpinnu**        | Kátálọ́ọ̀gù tí a pín jáde nìkan (`FREE_MODEL_BUDGETS` nínú `open-sse/config/freeModelCatalog.data.ts`) pẹ̀lú àwọn ìlànà ìfojúdìwọ̀n agbègbè (`:free` suffix, iye owó òdo, `grantsFreeAccess`) | Gbogbo ohun tó ń lo `src/shared/utils/freeModels.ts`: gbígbé model wọlé, ìtọ́sọ́nà `auto/*`, `GET /v1/models`, àti àwọn àwòtẹ́lẹ̀ inú aṣàwákiri |

Kíkà sí i lè túbọ̀ dára nígbàkigbà tí ìfúnni kan bá wà. Ṣíṣe ìpinnu dúró lórí ohun tí a pín jáde pẹ̀lú ìtẹ̀jáde náà, nítorí náà ìdáhùn náà jẹ́ ọ̀kan náà nínú aṣàwákiri àti lórí server, ó ṣeé tún ṣe láìsí ìsopọ̀ ayélujára, ó sì ṣeé dánwò láìsí database. Bí a bá jẹ́ kí àwòtẹ́lẹ̀ aṣàwákiri ka orísun kan nígbà tí gbígbé wọlé lórí server ka òmíràn, yóò mú àwòtẹ́lẹ̀ kan wá tí kò bá ohun tó ṣẹlẹ̀ nígbà títẹ̀ mu — a mọ̀ọ́mọ̀ pa ìpín yìí mọ́.

## Ọ̀nà ìṣe àti àwọn ohun tó yẹ kí a ṣọ́ra fún

- Àwọn nọ́ńbà jẹ́ **àwọn ìṣírò ààlà-òkè** láti inú àwọn ààlà ipele-ọ̀fẹ́ tí olùpèsè kọ̀ọ̀kan ṣàkọsílẹ̀ gẹ́gẹ́ bí ó ti rí ní **2026-06-17**, tí a kó jọ nípasẹ̀ ìwádìí lórí wẹ́ẹ̀bù. Àwọn ipele-ọ̀fẹ́ máa ń yí padà ní gbogbo ìgbà — tún un ṣàyẹ̀wò kí o tó gbára lé nọ́ńbà kan.
- **Ohun tí àkọsílẹ̀ kan ń fi ẹ̀rí múlẹ̀ gan-an.** Kò sí àkọsílẹ̀ kankan tó ní ìwọ̀n ìgbẹ́kẹ̀lé ti ìlà kọ̀ọ̀kan, API náà kò sì pèsè èyíkéyìí — ka gbogbo nọ́ńbà tó wà lókè sí ìṣírò tí gbogbo wọn ní dídára kan náà tí a kò sọ ní pàtó. Àwọn òtítọ́ méjì yàtọ̀, nítorí pé a fi ọwọ́ ṣètò wọn dípò kí a fà wọ́n jáde láti inú ìsọfúnni: àwọn àkọsílẹ̀ 44 ní ìdádúró líle tí a ṣàkọsílẹ̀ lọ́tọ̀ (39 nínú wọn ni àwọn ìlà xKiro, tí gbogbo wọn ń pín iye ìfàyègba ojoojúmọ́ kan náà), àwọn àkọsílẹ̀ 13 sì ní ìṣípayá nípa lílo prompt fún ìdánilẹ́kọ̀ọ́. A máa ń ṣètò `hardStopGuaranteed` nìkan nígbà tí àwọn òfin olùpèsè fúnra rẹ̀ sọ pé bí a bá kọjá iye ọ̀fẹ́, a ó kọ ìbéèrè náà dípò kí a bẹ̀rẹ̀ sí í gba owó lọ́nà tí a kò sọ, pẹ̀lú orísun nínú comment lẹ́gbẹ̀ẹ́ àkọsílẹ̀ náà; a kì í ṣètò rẹ̀ sí `true` gẹ́gẹ́ bí iye àkọ́ṣe láé, àkọsílẹ̀ tí ẹnikẹ́ni kò sì tíì fìdí rẹ̀ múlẹ̀ yóò dúró láìṣètò. Nítorí náà, àìsí àmì ìdádúró líle túmọ̀ sí "a kò tíì fìdí rẹ̀ múlẹ̀", kì í ṣe "a mọ̀ pé yóò gba owó lọ́wọ́ rẹ". **STRICT mode** (olùṣọ́ ìtọ́sọ́nà `freeAccessPolicy=strict` tí a yàn láti mú ṣiṣẹ́) gbẹ́kẹ̀lé àwọn àkọsílẹ̀ tó ní àmì náà nìkan; gbogbo ipele-ọ̀fẹ́ yòókù ni a yọ kúrò gẹ́gẹ́ bí `no-hard-stop` (wo `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Nígbà tí olùṣọ́ náà bá ṣe àlẹ̀mọ́ àkójọpọ̀ kan, àkọọlẹ̀ tí olùdarí lè rí máa ń jabo iye àwọn tí a yọ kúrò àti ìpín `no-hard-stop` wọn.
- `estMonthlyFreeTokens` = àwọn token oṣooṣù tó ń tún padà nìkan. **Àwọn kírẹ́díìtì ìforúkọsílẹ̀ ẹ̀ẹ̀kan kò tún padà** wọ́n sì ka sí 0. Àwọn ipele tí a ti fòpin sí tún jẹ́ 0.
- Ààlà token ojoojúmọ́ → `monthly = daily × 30`. Bí RPD nìkan ni a ṣàkọsílẹ̀ → `RPD × ~800 output tokens × 30`. Bí RPM/TPM nìkan ni (láìsí ààlà ojoojúmọ́) → **láìláàlà** (wo ìsàlẹ̀).
- **Ọ̀fẹ́ títí láé, ṣùgbọ́n kò sí ààlà token tí a tẹ̀ jáde** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ìwọ̀nyí jẹ́ àyè ọ̀fẹ́ gidi tó ń tún padà, tí ìwọ̀n lílò/ìṣiṣẹ́-pọ̀ ń díwọ̀n. A pín wọn sí `recurring-uncapped` a kò sì **kó àpapọ̀ wọn jọ láé** — ṣíṣòdipúpọ̀ `RPM × 24/7 × 30d` yóò dá àjàlé òkè àròsọ kan sílẹ̀ (ìfẹ́fẹ́ àlékún tí a kọ̀). A ṣe àkójọ wọn kí o lè mọ̀ pé wọ́n wà.
- **Ìgbéga tí ìfipamọ́ owó ṣí sílẹ̀:** àfikún owó kékeré ẹ̀ẹ̀kan tí ó ń gbé quota ọ̀fẹ́ sókè títí láé (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). A jabo rẹ̀ gẹ́gẹ́ bí nọ́ńbà ọ̀tọ̀, a sì yọ ọ́ kúrò nínú akọlé ìwọ̀n tí ó dúró ṣinṣin.
- **Àwọn quota tí ẹ̀tọ́ lílò díwọ̀n** (`eligibilityGate: "regional-identity"`): quota gidi tó ń tún padà, tí yóò ṣí sílẹ̀ lẹ́yìn àyẹ̀wò ìdánimọ̀ tó so mọ́ ẹkùn kan nìkan (ìjẹ́rìísí orúkọ-gidi ní ilẹ̀ Ṣáínà àárín ní òní). A kà á pẹ̀lú òfin yíyọ àtúnṣe inú àkójọpọ̀ kan náà sínú nọ́ńbà ọ̀tọ̀ (`gatedRecurringTokens`), kì í wọ inú akọlé ìwọ̀n tí ó dúró ṣinṣin láé. Ìlànà náà (`freeType`) kò yí padà, nítorí náà ìtọ́sọ́nà kò yí padà.
- **Àwọn ẹ̀ka ẹ̀rí.** Òfin náà ni pé: nọ́ńbà kan nínú kátálọ́ọ̀gù máa ń tọ́ka sí orísun rẹ̀ nínú comment `// evidence:` lẹ́gbẹ̀ẹ́ àkọsílẹ̀ náà — `public-page` (ojúewé olùpèsè tí ẹnikẹ́ni lè kà), `api-public` (endpoint olùpèsè tí kò nílò ìfàṣẹsí, fún àpẹẹrẹ endpoint ètò gbogbogbò ti NaraRouter ní router.bynara.id), tàbí `console-verified <date> por <who>` (nọ́ńbà náà hàn nínú console àkọọ́lẹ̀ nìkan; comment náà ṣàkọsílẹ̀ ẹni tó rí i àti ìgbà tó rí i, àti ojúewé gbogbogbò tó sọ pé ààlà náà wà). Ipò rẹ̀ lónìí: àwọn block márùn-ún tí a tún ṣàyẹ̀wò ní 2026-09-02 ní ẹ̀rí náà (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); àwọn àkọsílẹ̀ tó ti wà ṣáájú àtúnṣàyẹ̀wò 2026-09-02 jogún ìwádìí àkọ́kọ́ títí a ó fi tún fọwọ́ kàn wọ́n; nọ́ńbà **tuntun tàbí tí a yí padà** èyíkéyìí tí kò ní comment ẹ̀rí jẹ́ bug. Lónìí `mistral` nìkan ni console ti fìdí rẹ̀ múlẹ̀.

## Ìdí tí nọ́mbà wa fi kéré ju ti àwọn olùkójọpọ̀ mìíràn lọ

Ọ̀pọ̀ àwọn iye “tókìnì ọ̀fẹ́ fún oṣù kan” ní ààyè yìí jẹ́ àpapọ̀ àwọn àkọlé fún awoṣe kọ̀ọ̀kan. Tiwa kò rí bẹ́ẹ̀, a sì mọ̀ọ́mọ̀ ṣe é:

- **A ka àkójọpọ̀ tó jẹ́ pínpín kọ̀ọ̀kan lẹ́ẹ̀kan ṣoṣo.** Ètò ọ̀fẹ́ Mistral jẹ́ ìyọ̀ǹda 1B/oṣù kan fún àjọ kọ̀ọ̀kan; fífi í sí abẹ́ awoṣe márùn-ún kò sọ ọ́ di 5B. Bí a bá ṣàpapọ̀ rẹ̀ fún awoṣe kọ̀ọ̀kan, àkójọ tiwa fúnra wa yóò jẹ́ **~7.4B** (a tún ṣírò rẹ̀ ní 2026-09-03; CI kò fi dandan mú iye yìí — tún wọn-ọn nígbàkigbà tí àkójọ bá yí padà) — àkọlé náà sọ **~1.47B** nítorí pé ìyẹn ni ohun tí àkọọ́lẹ̀ kan láti ọ̀dọ̀ olùpèsè kọ̀ọ̀kan lè ná ní tòótọ́.
- **A ń yí àwọn òpin ojoojúmọ́ padà, kì í ṣe àwọn òṣùwọ̀n.** Òpin tokens/day tí a ṣàkọsílẹ̀ di `× 30`; òpin requests/day tí a ṣàkọsílẹ̀ di `RPD × ~800 tokens × 30`; olùpèsè tó bá ṣe àtẹ̀jáde requests-per-minute nìkan kò ní iye oṣooṣù **rárá**, a sì ṣe àkójọ rẹ̀ gẹ́gẹ́ bí _uncapped_, a kì í ṣàpapọ̀ rẹ̀ láé. Sísọ òpin òṣùwọ̀n di púpọ̀ nípa fífi 24/7 kún un ni ìmúpọ̀ iye tí a kọ̀ láti ṣe.
- **Àwọn ìpín tí ó wà lẹ́yìn àyẹ̀wò ìdánimọ̀ agbègbè ni a fi hàn lọ́tọ̀** (`+~6M behind regional identity verification`), nítorí pé ọ̀pọ̀ àwọn òǹkàwé kò lè lò wọ́n.
- **Àwọn kírẹ́díìtì ìforúkọsílẹ̀ wà fún oṣù àkọ́kọ́ nìkan** a sì ń jálẹ̀ wọn gẹ́gẹ́ bí iye kejì, a kì í da wọ́n pọ̀ mọ́ iye tó dúró ṣinṣin láé.
- **CI ń fipá mú kí iye náà péye.** `npm run check:docs-counts` tún ń ṣírò àpapọ̀ láti inú àkójọ, ó sì ń mú kí ìkọ́lé kùnà nígbà tí fáìlì yìí, README tàbí káàdì ètò ìnáwó bá yà kúrò lọ́dọ̀ wọn.

## Tábìlì àwọn ohun tó yẹ kí a kíyè sí nínú ToS

> **Àmì ToS jẹ́ ìmọ̀ràn, kì í ṣe ìdènà ìdarí.** Àwọn olùpèsè tí a fi àmì `tos` sí ṣì wà nínú ìdarí àti combo/fallback nípa àìrídìmú; àmì náà kàn máa ń hàn lórí `/dashboard/free-tiers` àti `/api/free-tier/summary`. Párámítà ìbéèrè `excludeTosAvoid` kan ìwò àkótán nìkan, kì í kan ìdarí àgbáyé. Ìpinnu náà wà nínú `open-sse/config/freeTierCatalog.ts` (fún ìfitónilétí, àwọn ẹ̀rọ ìdarí kì í kà á).

> Àkótán kíákíá nípa àwọn òfin olùpèsè kọ̀ọ̀kan fún aṣojú ara ẹni tí olùlò kan ṣoṣo gbàlejò fúnra rẹ̀. `caution` = gbólóhùn nípa lílò ara ẹni tàbí aṣojú tó yẹ kí a yẹ̀ wò; `ambiguous` = kò ṣe kedere; `ok` = a fàyè gbà á ní kedere. Fún ìfitónilétí, kì í ṣe ìmọ̀ràn òfin — ìwọ ló máa pinnu.

ìbéèrè (ìdájọ́ kan náà lórí gbogbo àkọọ́lẹ̀ fún ìrísí ìbéèrè kan náà), kì í ṣe ìdènà
àwòṣe tàbí àkókò ìdádúró àsopọ̀ — OmniRoute ń pín in sí `project_route_error`, ó fo
ìtìpa àwòṣe / àkókò ìdádúró, àti (lórí ipa ọ̀nà `noauth` àfọwọ́ṣe) ó dá àtúnyàn auto-combo
dúró fún TTL kúkúrú kan. Fi àwọn ìbéèrè tí ó ní àkójọ irinṣẹ́ tí kò ṣófo, `stream: true`, àti
àwọn akọ́lé session/UA OpenCode (`opencodeFreeTierContract.ts`) ránṣẹ́, bí bẹ́ẹ̀ kọ́, retí 403 náà.
